רשימות וטאפלים

list, index, פעולות עריכה, העתקה ו־tuple

שאלה מובילה: איך שומרים כמה פריטים תחת שם אחד?
לפתוח בצורך: במקום animal1, animal2, animal3 — משתמשים ברשימה אחת.
מהי רשימה?

רצף נתונים שניתן לעריכה

רשימה נשמרת בתוך משתנה ונכתבת עם סוגריים מרובעים.

animals = ["dog", "cat", "snake"]
numbers = [1, 2, 3]
x = [3.14, "hello", 7, True]
להדגיש שרשימה יכולה להכיל סוגים שונים, אבל לרוב נעדיף רצף עם משמעות אחת.
אינדקסים

הספירה מתחילה מ־0

כדי לגשת לאיבר כותבים את שם הרשימה ואת האינדקס בסוגריים מרובעים.

animals = ["dog", "cat", "snake", "cow"]
print(animals[1])  # cat
לשאול: מה האינדקס של האיבר הרביעי? תשובה: 3.
שגיאה נפוצה

אינדקס מחוץ לטווח

אם ניגשים למיקום שלא קיים ברשימה, פייתון תציג שגיאה.

animals = ["dog", "cat", "snake"]
print(animals[5])  # IndexError
להציג כשגיאה מועילה: היא אומרת לנו שביקשנו מקום שלא קיים.
רשימה ריקה ו־len

מתחילים ריק, בודקים אורך

רשימה ריקה שימושית כשאוספים קלטים בהמשך.

items = []
animals = ["dog", "cat", "snake"]
print(len(animals))  # 3
len מחזירה את מספר האיברים ברשימה.
append

מוסיפים איבר לסוף

append מוסיפה ערך חדש לסוף הרשימה.

animals = ["dog", "cat"]
animals.append("fish")
print(animals)
לתת לתלמידים לשנות את הערך שמוסיפים ולראות את התוצאה.
remove ו־pop

שתי דרכים למחוק

remove מוחקת לפי ערך. pop מוחקת לפי אינדקס, או את האחרון אם לא צוין אינדקס.

animals.remove("cat")
animals.pop(2)
animals.pop()
להדגיש: remove לערך שלא קיים גורמת לשגיאה; remove מוחקת רק את ההופעה הראשונה.
שינוי ערך

מציבים ערך חדש באינדקס

רשימה ניתנת לעריכה: אפשר להחליף איבר קיים.

animals = ["dog", "cat", "cow"]
animals[1] = "horse"
print(animals)
לחבר לאינדקסים: קודם מאתרים מקום, ואז מציבים בו ערך.
in

בדיקת קיום ברשימה

אפשר לבדוק האם ערך נמצא ברשימה בעזרת המילה השמורה in.

if "cow" in animals:
    print("Cow in animals.")
else:
    print("Cow not in animals.")
להזכיר שהבדיקה רגישה לערך המדויק, כולל אותיות גדולות/קטנות באנגלית.
copy

למה לא רק = ?

השמה רגילה יוצרת עוד שם לאותה רשימה. copy יוצרת רשימה חדשה.

l1 = animals
l1[0] = "frog"
l1 = animals.copy()
l1[0] = "frog"
זו נקודה מופשטת; מספיק שהתלמידים יבינו שכשרוצים עותק עצמאי משתמשים ב־copy.
for על רשימה

מעבר על כל הערכים

לולאת for שימושית מאוד למעבר על רצף נתונים כמו רשימה.

for animal in animals:
    print(animal)
להדגיש שמשתנה הלולאה מכיל את הערך הנוכחי.
שינוי רשימה בלולאה

צריך לעבוד עם אינדקסים

אם רוצים לשנות את הרשימה עצמה, משתמשים ב־range(len(...)).

for i in range(len(animals)):
    animals[i] = "frog"
להדגיש: שינוי animal בתוך for animal in animals לא משנה את האיבר המקורי.
טאפלים

רצף קבוע

tuple דומה לרשימה, אבל אי אפשר להוסיף, למחוק או לשנות את איבריו.

point = (10, 20)
colors = ("red", "green", "blue")
for color in colors:
    print(color)
להסביר שטאפל טוב למידע שלא אמור להשתנות.
תרגול כיתה

ארבע משימות

1. הדפסת איברי רשימה · 2. squared · 3. מחיקת כפילויות · 4. קליטת שמות עד stop

numbers = [1, 2, 3, 4, 5]
squared = []
for num in numbers:
    squared.append(num ** 2)
לתת לתלמידים זמן עצמאי. אפשר לפרק את משימת הכפילויות עם רשימה חדשה ובדיקת not in.
