בוליאנים ותנאים

True / False, אופרטורי השוואה, and/or/not, if/else/elif והזחות.

תוצר: מסווג גילאים עם בדיקת תקינות
פתיחה קצרה: עד עכשיו שמרנו מידע וחישבנו. היום התוכנית מתחילה לקבל החלטות.
Boolean

רק שתי אפשרויות

True / False

is_raining = True
is_sunny = False
print(str(is_raining))

  • יורד גשם?

להדגיש שבוליאני הוא לא טקסט "True" אלא ערך לוגי אמיתי.
השוואות

תנאי מחזיר True או False

שווה / שונה

score == 100
name != "Dana"

גדול / קטן

age > 12
age < 18

כולל שווה

age >= 18
age <= 120
חשוב: = שומר ערך במשתנה, == בודק שוויון.
אפשר לשאול “מה יודפס?” על כמה ביטויים לפני שמריצים.
לוגיקה

and / or / not

and / or

age = 14
has_ticket = True

print(age >= 12 and has_ticket)
print(age < 12 or has_ticket)

not

is_raining = False
print(not is_raining)

and דורש שני תנאים, or דורש לפחות אחד, not הופך את התוצאה.

לתת דוגמה יומיומית: נכנסים לסרט אם יש כרטיס וגם הגיל מתאים.
if

מריצים קוד רק אם התנאי מתקיים

age = int(input("Enter age: "))

if age >= 18:
    print("Adult")

אם התנאי True — נכנסים לבלוק. אם False — מדלגים עליו.

להסביר את הנקודתיים בסוף שורת if ואת ההזחה בשורה הבאה.
else

מה אם התנאי לא התקיים?

if age >= 18:
    print("Adult")
else:
    print("Not adult")

else מאפשר לתת תשובה גם במקרה שהתנאי לא נכון.

להריץ עם גיל 20 וגיל 10. לשאול איזו שורה רצה בכל פעם.
elif

שרשרת תנאים

if age < 4:
    print("Baby")
elif age < 13:
    print("Child")
elif age < 18:
    print("Teen")
else:
    print("Adult")

elif נבדק רק אם התנאים שלפניו לא התקיימו.

להסביר שרק בלוק אחד בשרשרת הזו אמור לרוץ.
הזחות

ב־Python רווחים הם חלק מהקוד

נכון

if age >= 18:
    print("Adult")
    print("Welcome")

לא נכון

if age >= 18:
print("Adult")

בלי הזחה נכונה הקוד לא יעבוד.

להדגיש 4 רווחים או Tab. אם העורך מסדר אוטומטית — עדיין צריך להבין למה.
תרגול כיתה

מסווג גילאים

קלט: גיל המשתמש. מתחת 0 או מעל 120 → Invalid age 0–3 → Baby 4–12 → Child 13–17 → Teen 18+ → Adult
לתת לתלמידים לנסות לבד לפני הפתרון. להזכיר שהסדר חשוב: קודם גיל לא תקין.
פתרון

מסווג גילאים

age = int(input("Enter age: "))

if age < 0 or age > 120:
    print("Invalid age")
elif age <= 3:
    print("Baby")
elif age <= 12:
    print("Child")
elif age <= 17:
    print("Teen")
else:
    print("Adult")
להריץ עם -1, 2, 8, 15, 18, 130. להסביר למה לא צריך age >= 18 ב-else.
