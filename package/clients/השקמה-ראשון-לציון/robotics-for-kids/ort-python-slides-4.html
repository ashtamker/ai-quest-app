לולאות

while, for, range, break ו־continue

שאלה מובילה: איך גורמים למחשב לחזור על פעולה בלי לשכפל קוד?
לפתוח בצורך: מה יקרה אם צריך להדפיס אותו רצף 100 פעמים? מכאן מציגים לולאה ככלי שחוסך שכפול ומקטין טעויות.
מהי לולאה?

קטע קוד שחוזר על עצמו

לולאה מאפשרת להריץ אותו קטע קוד מספר פעמים. במקום להעתיק קוד שוב ושוב — מגדירים תנאי או רצף חזרות.

שני סוגים מרכזיים: while כאשר יש תנאי מתמשך, ו־for כאשר עוברים על רצף או מספר חזרות ידוע.

להדגיש: קוד משוכפל קשה לתקן. אם יש באג בשכפול — צריך לתקן הרבה מקומות. לולאה עוזרת לכתוב קוד נקי ואלגנטי.
while

כל עוד תנאי מתקיים

לולאת while מריצה קוד כל עוד התנאי הוא True.

i = 0
while i < 5:
    print(i)
    i += 1

בכל חזרה מדפיסים את i ומגדילים אותו ב־1.

לשאול: מה יקרה אם נמחק את i += 1? לכוון לכך שהלולאה לא תיעצר כי התנאי תמיד יישאר נכון.
import ו־random

לולאה עד שמתקבל מספר

import random

n = 0
while n != 3:
    n = random.randint(0, 9)
    print(n)

import מזמן ספרייה. randint מחזירה מספר אקראי בטווח כולל.

להסביר שלא תמיד יודעים מראש כמה פעמים הלולאה תרוץ. היא ממשיכה עד ש־n שווה 3.
דגש קריטי

הזחה היא חלק מהקוד

כל קטע קוד שמתבצע בכל חזרה של הלולאה חייב להיות מוזח פנימה.

while i < 5:
    print(i)
    i += 1

אם שורה לא מוזחת נכון — היא לא חלק מהלולאה או שתתקבל שגיאת תחביר.

להראות בכיתה דוגמה עם הזחה שגויה אם יש זמן. זה אחד המקומות הנפוצים לשגיאות אצל תלמידים.
for

מעבר על רצף ידוע

לולאת for מתאימה כשמספר החזרות ידוע מראש או כשעוברים על רצף נתונים.

for i in range(10):
    print(i)
להדגיש ש־range(10) לא כולל את 10. הפלט הוא 0 עד 9.
range

start · stop · step

range(stop)

range(10)

0 עד 9

range(start, stop)

range(1, 10)

1 עד 9

range(start, stop, step)

range(1, 10, 2)

1, 3, 5, 7, 9

ה־stop הוא אחד מעל הערך האחרון. step הוא גודל הקפיצה.
לולאה + תנאי

מדפיסים רק מה שמתאים

for num in range(1, 11):
    if num % 2 == 0:
        print(num)

הסימן % מחזיר שארית. כאן מדפיסים רק מספרים זוגיים.

לחבר לשיעור הקודם על תנאים ובוליאנים. הלולאה עוברת על כל המספרים, התנאי מחליט מה יודפס.
break

עוצרים את הלולאה

for x in range(5):
    if x != 0 and x % 3 == 0:
        break
    print(x)

כאשר הקוד מגיע ל־break, ריצת הלולאה נפסקת מיד.

להריץ ולשאול לפני ההרצה: מה יודפס? להסביר למה x=3 עוצר את הלולאה.
continue

מדלגים לחזרה הבאה

for x in range(1, 5):
    if x % 3 == 0:
        continue
    print(x)

continue לא עוצר את כל הלולאה — הוא מדלג רק על המשך החזרה הנוכחית.

להבדיל במפורש בין break לבין continue: break יוצא מהלולאה, continue ממשיך לחזרה הבאה.
תרגול כיתה 1

קלט עד הספרה 4

כתבו קוד שקולט ערכים מהמשתמש בלולאה כל עוד המשתמש לא הזין את הספרה 4. כשהוזנה הספרה 4 — הקוד נעצר.

value = input("הכניסו מספר: ")
while value != "4":
    value = input("נסו שוב: ")
print("עצירה")
לתת לתלמידים לכתוב לבד לפני שמציגים פתרון. להזכיר שקלט מ־input הוא מחרוזת ולכן משווים ל־"4".
תרגול כיתה 2

מספרים אי־זוגיים שמתחלקים ב־3

הדפיסו את כל המספרים בין 1 ל־100 שהם אי־זוגיים וגם מתחלקים ב־3 ללא שארית.

for num in range(1, 101):
    if num % 2 != 0 and num % 3 == 0:
        print(num)
אם קשה, לפרק: קודם מדפיסים 1 עד 100, אחר כך מוסיפים תנאי אי־זוגי, ואז תנאי חלוקה ב־3.
