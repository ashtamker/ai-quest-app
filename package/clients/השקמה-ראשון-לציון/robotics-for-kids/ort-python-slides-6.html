הבעיה

הפתרון

מגדירים פעולה פעם אחת, נותנים לה שם, וקוראים לה כשצריך.

לבקש דוגמאות מהתלמידים: תפריט, ממוצע, בדיקה, ציור חוזר.

מושג ראשון

פונקציה היא קטע קוד עם שם

כותבים את הפעולה פעם אחת, ואז מפעילים אותה לפי הצורך.

שם

מתאר מה הפעולה עושה.

גוף

השורות שרצות כשקוראים לפונקציה.

קריאה

הפקודה שמפעילה את הפונקציה.

להדגיש: שם משמעותי, אותיות קטנות, כמו במשתנים.
מבנה בסיסי

def + שם + סוגריים

def name(): # code inside the function name()

הקוד שבתוך הפונקציה חייב להיות מוזח פנימה.

להראות על המסך את ההבדל בין הגדרה לבין קריאה.
נקודה חשובה

פונקציה לא רצה לבד

רק הגדרה

Python יודע שהפונקציה קיימת, אבל לא מפעיל אותה.

קריאה לפונקציה

רק כשכותבים name() הקוד שבתוכה רץ.

שגיאה נפוצה: תלמידים כותבים פונקציה ולא קוראים לה.
דוגמה

print_menu

def print_menu(): print(""" Welcome to the Menu! 1. Signup 2. Signin 3. Exit """) print_menu()
להסביר בקצרה ששלוש מירכאות מאפשרות טקסט רב־שורות.
פרמטרים

שולחים מידע לפונקציה

לפעמים הפונקציה צריכה לקבל ערך כדי לבצע את העבודה שלה.

def nextYear(age): age += 1 print("Next year you will be " + str(age)) nextYear(15) nextYear(12) nextYear(20)
age הוא שם זמני בתוך הפונקציה. הערך האמיתי מגיע בזמן הקריאה.
כמה פרמטרים

הסדר חשוב

def name(op1, op2, op3): # the function name(10, "hello", False)

op1

מקבל 10.

op2

מקבל "hello".

op3

מקבל False.

להדגיש: ערכים נכנסים לפרמטרים לפי סדר.
תרגול

printBigger

פונקציה שמקבלת שני מספרים ומדפיסה את הגדול מביניהם.

def printBigger(num1, num2): if num1 > num2: print(str(num1)) else: print(str(num2)) printBigger(1, 2) printBigger(3, -6) printBigger(5, 5)
לתת 6–8 דקות עבודה. לבדוק גם מקרה של מספרים שווים.
return

לפעמים לא מדפיסים — מחזירים

print

מציג למסך. קשה להשתמש בתוצאה בהמשך.

return

מחזיר ערך שאפשר לשמור במשתנה או להעביר הלאה.

זה מעבר חשוב. לא להעמיס; להתמקד בשמירת תוצאה במשתנה.
דוגמה

average

def average(num1, num2): return (num1 + num2) / 2 avg = average(100, 90) print(str(avg))

הפונקציה מחזירה 95.0, ואנחנו שומרים את הערך במשתנה.

להראות שאפשר גם print(str(average(100, 90))) אבל עדיף לשמור כשצריך להשתמש בהמשך.
חיבור פונקציות

ifPass משתמשת ב־average

def average(num1, num2): return (num1 + num2) / 2 def ifPass(grade1, grade2): avg = average(grade1, grade2) if avg <= 55: print("Failed") else: print("Average is " + str(avg))
להדגיש מבנה טוב: פונקציה אחת מחשבת, פונקציה אחרת מקבלת החלטה.
