משתנים: איך שומרים מידע?

לומדים לשמור מספרים וטקסט בזיכרון התוכנית, לבצע פעולות חשבון, לחבר מחרוזות, להמיר בין מספר לטקסט, ולהדפיס תוצאות בצורה ברורה.

תוצר יציאהחישוב גילאי בני הבית: סכום, מכפלה, חלוקה, והדפסת התוצאות.
מושגיםvariable · מספרים · string · naming · + - * / · ** · % · str() · int()
מה לא עושים כאןבהמשך אפשר לבנות פעילות אישית לכל תלמיד לפי ההתקדמות שלו.

1 · מהו משתנה?

משתנים הם כמו מגירות אחסון בזיכרון התוכנית. אנחנו נותנים שם למגירה ושומרים בה מידע.

מה אפשר לשמור?

  • מספרים שלמים: 18
  • מספרים עשרוניים: 0.3
  • טקסט ומילים: "James"
  • תווים וסימנים

דוגמה ראשונה

points = 18
x = 100
speed = 0.3
name = "Alice"

2 · הסכמה בשמות משתנים

שם טוב עוזר לנו להבין מה שמור במשתנה גם אחרי שהקוד גדל.

כללים פשוטים

  • מתחילים באותיות קטנות.
  • שם צריך להיות משמעותי.
  • אם יש כמה מילים: משתמשים ב־_ או באות גדולה.

דוגמאות

my_name = "Dana"
myName = "Dana"
num_of_siblings = 3
sumOfAges = 111
שאלה: איזה שם משתנה ברור יותר — x או player_score?

3 · משתנים מספריים ופעולות חשבון

על מספרים אפשר לבצע פעולות חשבון בדיוק כמו במחברת — אבל בתוך קוד.

ארבע פעולות

points = 18 + 1
x = 100 - 50
y = 20 * 8
speed = 0.3 / 10

סימני הפעולות

  • חיבור: +
  • חיסור: -
  • כפל: *
  • חילוק: /

4 · שינוי ערך של משתנה וקיצורים

משתנה יכול לקבל ערך חדש שמבוסס על הערך הקודם שלו.

עדכון רגיל

points = 5
points = points + 3

speed = 0.5
speed = speed - 0.1

דרך קיצור

x = 10
x += 5
x *= 7
x /= 3

הקיצור אומר: קח את הערך הקיים, בצע פעולה, ושמור שוב באותו משתנה.

5 · חזקות ומודולו

חזקות עם **

שתי כוכביות מחשבות חזקה.

power = 2 ** 7
print(power)

מודולו עם %

מודולו מחזיר את השארית בחלוקה.

x = 5 % 2
print(x)  # 1

y = 11 % 3
print(y)  # 2

6 · תרגול כיתה: גילאי בני הבית

נגדיר גיל לכל בן בית, ואז נחשב סכום, מכפלה וחלוקה.

המשימה

  1. הגדירו משתנה לגיל של כל אחד מבני הבית.
  2. שמרו את סכום הגילאים במשתנה sumOfAges.
  3. שמרו את מכפלת הגילאים במשתנה mulOfAges.
  4. שמרו במשתנה div את המכפלה חלקי הסכום.

פתרון לדוגמה

age1 = 18
age2 = 46
age3 = 44
age4 = 3

sumOfAges = age1 + age2 + age3 + age4
mulOfAges = age1 * age2 * age3 * age4
div = mulOfAges / sumOfAges

7 · מחרוזות ושרשור

מחרוזת היא טקסט בתוך מרכאות. אפשר לחבר מחרוזות בעזרת +.

מחרוזות

firstName = "James"
lastName = "Lacey"
space = " "

שרשור

fullName = firstName + " " + lastName
print(fullName)

אם רוצים רווח בין מילים — מוסיפים מחרוזת שמכילה רווח.

8 · הדפסת משתנים והמרות

כשמדפיסים משתנה — לא שמים אותו בתוך מרכאות. כשמחברים מספר לטקסט, ממירים אותו עם str().

הדפסת תוצאות התרגיל

print("Sum of ages: " + str(sumOfAges))
print("Mul of ages: " + str(mulOfAges))
print("Div: " + str(div))

input ו־int

name = input("What is your name? ")
age = int(input("Enter age: "))

print("My name is " + name)
print("I'm " + str(age) + " years old")

int() הופך טקסט למספר. str() הופך מספר לטקסט.
