משתנים

שומרים מידע בזיכרון התוכנית: מספרים, מחרוזות, חישובים, המרות וקלט מהמשתמש.

תוצר: חישוב והדפסת נתוני גילאי בני הבית
להזכיר בקצרה את שיעור 1: print, input, מחרוזות ומשתנים ראשונים. היום מעמיקים במשתנים ובפעולות עליהם.
מושג מרכזי

משתנה הוא מגירת אחסון

במהלך תוכנית נרצה לשמור נתונים: מספרים שלמים, מספרים עשרוניים, טקסט ותווים.

דוגמאות

points = 18
x = 100
speed = 0.3
name = "Alice"

שאלה לכיתה

איזה מידע משחק מחשב צריך לזכור בזמן משחק?

להשתמש בדימוי של מגירות/קופסאות. הדגש: שם המשתנה עוזר לנו למצוא את המידע בהמשך.
שמות משתנים

שם טוב חוסך בלבול

כללים

  • מתחילים באותיות קטנות.
  • נותנים שם משמעותי.
  • כמה מילים: _ או אות גדולה.

דוגמאות

my_name = "Dana"
myName = "Dana"
num_of_siblings = 3
sumOfAges = 111
להציג גם שם לא טוב כמו x, ולהראות מתי x יכול להיות סביר ומתי עדיף שם מלא.
מספרים

משתנים מספריים

על משתנים שמכילים מספר אפשר לבצע פעולות חשבון.

points = 18 + 1
x = 100 - 50
y = 20 * 8
speed = 0.3 / 10
+ חיבור · - חיסור · * כפל · / חילוק
לשאול לפני הרצה: מה יהיה הערך של כל משתנה? ואז להריץ ולהשוות.
עדכון ערך

משתנה יכול להשתנות

מבוסס על הערך הקודם

points = 5
points = points + 3

speed = 0.5
speed = speed - 0.1

קיצורים

x = 10
x += 5
x *= 7
x /= 3
להדגיש: השורה מימין לשווה מחושבת קודם, ואז נשמרת מחדש בשם המשתנה.
עוד אופרטורים

חזקות ומודולו

חזקות **

power = 2 ** 7
print(power)

מודולו %

x = 5 % 2   # 1
y = 11 % 3  # 2

מודולו מחזיר את השארית בחלוקה.

מודולו יכול להיות מופשט. להסביר עם 5 ממתקים שמחלקים ל-2 ילדים ונשאר 1.
תרגול כיתה

גילאי בני הבית

הגדירו משתנה לגיל של כל בן בית. שמרו סכום ב-sumOfAges. שמרו מכפלה ב-mulOfAges. שמרו ב-div את המכפלה חלקי הסכום.
זה התרגול המרכזי. לתת לתלמידים כמה דקות לפני הצגת פתרון. מי שאין לו רעיון — יכול להשתמש במספרים לדוגמה.
פתרון לדוגמה

חישוב גילאים

age1 = 18
age2 = 46
age3 = 44
age4 = 3

sumOfAges = age1 + age2 + age3 + age4
mulOfAges = age1 * age2 * age3 * age4
div = mulOfAges / sumOfAges
להסביר ששמות כמו age1 עובדים, אבל אם רוצים קוד ברור יותר אפשר להשתמש בשמות כמו myAge, momAge וכו׳.
מחרוזות

טקסט בתוך מרכאות

מחרוזות הן טקסט: אותיות, רווחים, תווים וסימנים.

firstName = "James"
lastName = "Lacey"
space = " "

fullName = firstName + " " + lastName
print(fullName)
להדגיש את הרווח: אם לא נוסיף " ", השמות יידבקו.
הדפסה והמרות

str() ו-int()

מספר לטקסט

print("Sum of ages: " + str(sumOfAges))
print("Mul of ages: " + str(mulOfAges))
print("Div: " + str(div))

טקסט למספר

age = int(input("Enter age: "))
newAge = age + 1
print("Next year: " + str(newAge))
להסביר: input מחזיר טקסט. כדי לחשב עם התשובה צריך int(). כדי לחבר מספר למשפט צריך str().
קלט מהמשתמש

שומרים תשובות במשתנים

name = input("What is your name? ")
age = int(input("Enter age: "))
city = input("Enter city: ")

print("My name is " + name)
print("I'm " + str(age) + " years old")
print("I live in " + city)
אפשר להשתמש בזה כתרגול קצר בכיתה אם יש זמן.
