1 · למה בכלל Python?

Python היא שפה ידידותית למתחילים אבל גם שפה אמיתית שמקצוענים משתמשים בה.

קלה לקריאה

התחביר שלה ברור יחסית, ולכן אפשר להבין מהר מה הקוד עושה.

רב־תכליתית

משתמשים בה לאתרים, משחקים, ניתוח נתונים, בינה מלאכותית, רובוטיקה וכלי אוטומציה.

שימוש מקצועי

חברות גדולות וצוותי פיתוח משתמשים ב-Python בגלל הפשטות והעוצמה שלה.

כיף ויצירתי

אפשר לבנות משחקים, סיפורים אינטראקטיביים, ציורים וכלים קטנים כבר בשלבים הראשונים.

2 · סביבת עבודה — בקצרה

בשיעור הזה עובדים עם עורך Python אונליין כדי שכולם יוכלו להתחיל מיד.

מה עושים עכשיו?

  1. פותחים עורך Python אונליין שהמדריך בוחר.
  2. כותבים קוד באזור העריכה.
  3. לוחצים Run ומסתכלים על הפלט.

מה בהמשך?

אפשר לעבוד גם עם PyCharm או Python IDLE במחשב, אבל היום המטרה היא להבין את הרעיון ולא להיתקע על התקנות.

3 · תוכנית ראשונה: Hello, World!

תוכנית היא אוסף הוראות למחשב. ההוראה הראשונה שלנו מדפיסה הודעה למסך.

# Print the message "Hello, World!" on the screen
print("Hello, World!")
משימה קצרה: שנו את הטקסט שבתוך המרכאות והריצו שוב. לדוגמה: שם שלכם, משפט מצחיק או הודעת פתיחה.

4 · הערות בקוד ומחרוזות

Comment · הערה

שורה שמתחילה ב־# היא הסבר למי שקורא את הקוד. המחשב לא מריץ אותה.

# This is a comment

String · מחרוזת

טקסט בתוך מרכאות נקרא מחרוזת. לדוגמה: "Hello" או "שלום".

print("שלום עולם!")

5 · מה הם משתנים?

משתנה הוא כמו קופסה עם שם. שומרים בו מידע כדי להשתמש בו מאוחר יותר.

הקצאת ערכים

name = "Alice"
age = 12

שם המשתנה צריך להיות משמעותי כדי שנבין מה שמור בו.

שימוש במשתנים בפלט

name = "Alice"
age = 12
print("Hello, " + name + "! You are " + str(age) + " years old.")

+ מחבר מחרוזות, ו־str() הופך מספר לטקסט כדי שאפשר יהיה לחבר אותו למשפט.

6 · קלט מהמשתמש וברכה אישית

עכשיו התוכנית לא רק מדפיסה — היא שואלת את המשתמש ומשתמשת בתשובה.

name = input("מה השם שלך? ")
age = input("בן/בת כמה את/ה? ")
print("שלום, " + name + "!")
print("איזה כיף ללמוד Python בגיל " + age)
תרגול: בנו תוכנית שמבקשת שם, תחביב וצבע אהוב, ואז מדפיסה כרטיס היכרות קצר.
