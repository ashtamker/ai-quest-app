בוליאנים ותנאים

לומדים איך Python בודקת אם משהו נכון או לא נכון, ואז מריצה קוד אחר לפי התוצאה.

תוצר יציאהתוכנית שמקבלת גיל ומחזירה: תינוק, ילד, נער, מבוגר או גיל לא תקין.

1 · משתנים בוליאניים

Boolean הוא ערך שיכול להיות רק אחד משניים: אמת או שקר.

True / False

is_raining = True
is_sunny = False
print(str(is_raining))

כדי לחבר בוליאני לטקסט או להדפיס בתוך משפט, אפשר להמיר אותו עם str().

תנאי מהחיים

  • האם יורד גשם?
  • האם השעה היא 17:00?
  • האם המשתמש מעל גיל 18?

2 · אופרטורים לבדיקת תנאים

השוואה מחזירה תמיד תוצאה בוליאנית: True או False.

שווה / לא שווה

score == 100
name != "Dana"

גדול / קטן

age > 12
age < 18

כולל שווה

age >= 18
age <= 120
חשוב: ב־Python השוואה לשוויון היא ==, לא =. סימן = משמש להשמה במשתנה.

3 · אופרטורים לוגיים: and / or / not

and / or

age = 14
has_ticket = True

print(age >= 12 and has_ticket)
print(age < 12 or has_ticket)

not

is_raining = False
print(not is_raining)
  • and: שני התנאים חייבים להתקיים.
  • or: מספיק שתנאי אחד יתקיים.
  • not: הופך True ל־False ולהפך.

4 · if: להריץ קוד רק אם תנאי מתקיים

פקודת if יוצרת בלוק קוד שירוץ רק אם התנאי הוא True.

age = int(input("Enter age: "))

if age >= 18:
    print("Adult")
אם התנאי לא מתקיים — Python פשוט מדלגת על הבלוק.

5 · else ו־elif

else

רץ כאשר התנאי של ה־if לא התקיים.

if age >= 18:
    print("Adult")
else:
    print("Not adult")

elif

בודק תנאי נוסף רק אם התנאים שלפניו לא התקיימו.

if age < 4:
    print("Baby")
elif age < 13:
    print("Child")
else:
    print("Teen or adult")

6 · הזחות בפייתון

ב־Python הזחה קובעת איזה קוד שייך לבלוק. בדרך כלל משתמשים ב־4 רווחים או Tab.

נכון

if age >= 18:
    print("Adult")
    print("Welcome")

לא נכון

if age >= 18:
print("Adult")

אם ההזחה לא נכונה — הקוד לא יעבוד.

7 · תרגיל כיתה: מסווג גילאים

נבקש מהמשתמש גיל ונחזיר קטגוריה מתאימה.

החוקים

  • מתחת ל־0 או מעל 120: גיל לא תקין
  • 0–3: תינוק
  • 4–12: ילד
  • 13–17: נער
  • 18 ומעלה: מבוגר

פתרון לדוגמה

age = int(input("Enter age: "))

if age < 0 or age > 120:
    print("Invalid age")
elif age <= 3:
    print("Baby")
elif age <= 12:
    print("Child")
elif age <= 17:
    print("Teen")
else:
    print("Adult")
נסו להריץ עם: -1, 2, 8, 15, 18, 130. האם כל תוצאה נכונה?
