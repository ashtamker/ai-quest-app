רשימות וטאפלים

איך שומרים רצף נתונים, ניגשים אליו, משנים אותו ועוברים עליו בלולאה?

מטרת השיעורלהבין רשימה כרצף נתונים ניתן לעריכה, ולהכיר tuple כרצף קבוע.
מושגיםlist · index · len · append · remove · pop · in · copy · tuple
תוצר יציאהקוד שמדפיס, משנה, מעתיק ומעבד רשימות בעזרת לולאות.

מהי רשימה?

רשימה היא רצף נתונים שניתן לערוך ולשמור בתוך משתנה אחד. בפייתון כותבים רשימה עם סוגריים מרובעים.

רשימת מחרוזות

animals = ["dog", "cat", "snake", "cow"]

רשימת מספרים ורשימה מעורבת

numbers = [2, 4, 6, 8]
x = [3.14, "hello", 7, True]

רשימה יכולה להכיל ערכים מסוגים שונים, למרות שלרוב נעדיף לשמור בה פריטים מאותו סוג.

אפשר ליצור רשימה ריקה כך: items = []. אפשר גם לרוקן רשימה קיימת על ידי הצבה של רשימה ריקה.

אינדקסים וגישה לאיברים

כדי לגשת לאיבר ברשימה מציינים את האינדקס שלו. בפייתון הספירה מתחילה מ־0.

גישה לאיבר

animals = ["dog", "cat", "snake", "cow"]
print(animals[1])  # cat

האיבר השני נמצא באינדקס 1.

שינוי ערך

animals[1] = "horse"
print(animals)

כך מחליפים את הערך שנמצא באינדקס מסוים.

גישה לאינדקס מחוץ לטווח תגרום לשגיאה. למשל אינדקס 5 ברשימה בעלת 3 איברים.

פעולות נפוצות על רשימות

len · אורך רשימה

animals = ["dog", "cat", "snake"]
print(len(animals))  # 3

append · הוספה לסוף

animals.append("fish")
print(animals)

in · בדיקת קיום

if "cow" in animals:
    print("Cow in animals.")
else:
    print("Cow not in animals.")

remove · מחיקה לפי ערך

animals = ["dog", "cat", "snake", "cat"]
animals.remove("cat")
print(animals)

remove מוחקת את ההופעה הראשונה של הערך. אם הערך לא קיים — תתקבל שגיאה.

pop · מחיקה לפי אינדקס

animals = ["dog", "cat", "snake", "cow"]
animals.pop(2)   # מוחק את snake
animals.pop()    # מוחק את האיבר האחרון
print(animals)

העתקת רשימות

רשימה היא אובייקט. אם מציבים רשימה במשתנה חדש בצורה רגילה, שני המשתנים מצביעים לאותה רשימה.

מה עלול לבלבל?

animals = ["dog", "cat", "cow"]
l1 = animals
l1[0] = "frog"
print(animals)  # גם animals השתנתה

העתקה בטוחה

animals = ["dog", "cat", "cow"]
l1 = animals.copy()
l1[0] = "frog"
print(animals)
print(l1)

copy יוצרת רשימה חדשה עם אותם הערכים.

רשימות ולולאת for

אפשר לעבור על כל איברי הרשימה בלולאה. אם רוצים רק להדפיס — עוברים על הערכים. אם רוצים לשנות — כדאי להשתמש באינדקסים.

מעבר על ערכים

animals = ["dog", "cat", "cow"]
for animal in animals:
    print(animal)

animal מכיל בכל חזרה את הערך של האיבר הנוכחי.

שינוי איברים עם range

animals = ["dog", "cat", "cow"]
for i in range(len(animals)):
    animals[i] = "frog"
print(animals)

כאן משתמשים באינדקס כדי לשנות את הרשימה עצמה.

שינוי של משתנה הלולאה בלבד לא משנה את האיבר המקורי ברשימה.

טאפלים

טאפל דומה לרשימה, אבל הוא קבוע: אי אפשר להוסיף, למחוק או לשנות איברים אחרי יצירתו. כותבים אותו עם סוגריים רגילים.

יצירת tuple

point = (10, 20)
colors = ("red", "green", "blue")

מעבר על tuple

for color in colors:
    print(color)

כי גם tuple הוא רצף נתונים.

תרגול כיתה

1 · הדפסת איברי רשימה

animals = ["dog", "cat", "snake", "cow"]
for animal in animals:
    print(animal)

2 · רשימת ריבועים

numbers = [1, 2, 3, 4, 5]
squared = []
for num in numbers:
    squared.append(num ** 2)
print(squared)

3 · מחיקת כפילויות

lst = [1, 2, 2, 3, 1, 4]
no_duplicates = []
for item in lst:
    if item not in no_duplicates:
        no_duplicates.append(item)
print(no_duplicates)

4 · קליטת שמות עד stop

names = []
name = input("הכניסו שם: ")
while name != "stop":
    names.append(name)
    name = input("הכניסו שם: ")
print(names)
