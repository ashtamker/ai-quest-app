בשימוש מקצועי

יצירתית

עם מעט שורות קוד אפשר ליצור משחק, סיפור אינטראקטיבי או כלי שימושי.

זה סעיף חשוב. לשמור על הסבר חי ומעורר סקרנות, אבל לא להאריך מדי.
סביבת עבודה

היום עובדים בעורך אונליין

למה?

  • כולם מתחילים מהר.
  • אין עיכוב על התקנות.
  • אפשר לראות קוד ופלט מיד.

מה כן מזכירים?

בהמשך אפשר לעבוד גם עם PyCharm או Python IDLE. היום מספיק לדעת: כותבים קוד → לוחצים Run → קוראים פלט.

לתת קישור לעורך אונליין שבחרתם. לא להיתקע על התקנות. אם תלמיד תקוע טכנית — לתת לו לעבוד בזוג.
מושג בסיס

מהי תוכנית?

תוכנית היא רצף הוראות למחשב. המחשב לא “מנחש” — הוא עושה בדיוק את מה שכתבנו, לפי הסדר.

שאלה לכיתה: אם נשנה שורה אחת בקוד, מה לדעתכם ישתנה בפלט?
לחבר לסדר פעולות: כל שורה היא הוראה. זו הכנה טובה ל-debug בהמשך.
קוד ראשון

Hello, World!

# Print the message "Hello, World!" on the screen
print("Hello, World!")

מריצים, רואים פלט, ואז משנים את הטקסט בתוך המרכאות.

להקליד יחד עם התלמידים. להסביר שזו מסורת בעולם התכנות: התוכנית הראשונה מדפיסה Hello World.
הסבר קוד

מה קורה כאן?

# comment

הערה בקוד. המחשב לא מריץ אותה — היא עוזרת לנו להסביר.

print()

פונקציה שמציגה הודעה או ערך על המסך.

"Hello"

טקסט בתוך מרכאות נקרא מחרוזת — string.

להדגיש: אם נשכח מרכאות סביב טקסט, נקבל שגיאה. זו הזדמנות לדבר על שגיאה כמידע.
משימה קצרה

משנים את ההודעה

1. החליפו את Hello, World בשם שלכם. 2. הדפיסו משפט שני. 3. הריצו שוב ובדקו מה השתנה.
print("שלום, אני דנה")
print("זה הקוד הראשון שלי!")
זו הצלחה מהירה. לעבור בין תלמידים ולוודא שכולם ראו פלט במסך.
משתנים

משתנה הוא קופסה עם שם

משתנה שומר מידע כדי שנוכל להשתמש בו מאוחר יותר.

name = "Alice"
age = 12
כלל חשוב: שם המשתנה צריך להיות משמעותי.
לתת דוגמה מחיי היומיום: קופסה שכתוב עליה “צעצועים” או צנצנת שכתוב עליה “עוגיות”.
משתנים בפלט

מחברים טקסט ומשתנים

name = "Alice"
age = 12
print("Hello, " + name + "! You are " + str(age) + " years old.")

+

מחבר מחרוזות לחלקי משפט.

str()

הופך מספר לטקסט כדי שאפשר יהיה לשלב אותו במשפט.

לא להעמיק מדי בטיפוסים. מספיק להבין שמספר וטקסט הם סוגים שונים, ולכן לפעמים צריך המרה.
קלט מהמשתמש

input(): המחשב שואל

name = input("מה השם שלך? ")
age = input("בן/בת כמה את/ה? ")
print("שלום, " + name + "!")
print("איזה כיף ללמוד Python בגיל " + age)

עכשיו התוכנית מגיבה למידע שהמשתמש מקליד.

זו הרחבה מהתקציר של המפגש. להראות שתוכנית יכולה להיות אינטראקטיבית ולא רק להדפיס טקסט קבוע.
