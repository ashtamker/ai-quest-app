הופכים קוד שחוזר על עצמו לפונקציה

לומדים להגדיר פונקציה, לקרוא לה, לשלוח לה פרמטרים ולקבל ממנה ערך חזרה כדי לכתוב קוד מסודר ושימושי יותר.

תוצר יציאהקובץ Python עם כמה פונקציות קצרות: תפריט, גיל בשנה הבאה, מספר גדול, ממוצע ובדיקת מעבר.
שאלה מובילהמתי כדאי להפוך שורות קוד לפונקציה?
כלל זהבפונקציה לא רצה רק כי כתבנו אותה — צריך לקרוא לה.

התקדמות

0 מתוך 7 שלבים סומנו.

שלב 1 · למה צריך פונקציות?

כאשר פעולה חוזרת במקומות שונים בקוד, לא נרצה להעתיק שוב ושוב את אותן שורות.

בלי פונקציה

אותו קטע קוד מודבק בכמה מקומות. אם רוצים לשנות אותו, צריך לזכור לשנות בכל מקום.

עם פונקציה

כותבים את הפעולה פעם אחת, נותנים לה שם, וקוראים לה בכל פעם שצריך.

שלב 2 · מגדירים פונקציה וקוראים לה

מגדירים פונקציה עם def, שם, סוגריים ונקודתיים. הקוד שבתוכה מוזח פנימה.

def name(): # code inside the function name()
חשוב: אם הפונקציה כתובה בקובץ אבל לא קראנו לה, הקוד שבתוכה לא יפעל.

שלב 3 · פונקציית תפריט

ניצור פונקציה שמדפיסה תפריט פשוט, ואז נקרא לה כדי לראות שהיא עובדת.

def print_menu(): print(""" Welcome to the Menu! 1. Signup 2. Signin 3. Exit """) print_menu()
שלוש מירכאות מאפשרות להדפיס טקסט בכמה שורות.

שלב 4 · פונקציה עם פרמטרים

לפעמים נרצה לשלוח ערכים לפונקציה. הערכים נכנסים לפי הסדר לפרמטרים שבסוגריים.

def nextYear(age): age += 1 print("Next year you will be " + str(age)) nextYear(15) nextYear(12) nextYear(20)

פרמטר

שם זמני בתוך הפונקציה, למשל age.

ערך שנשלח

הערך בקריאה לפונקציה, למשל 15.

פרמטר
ערך לדוגמה

שלב 5 · printBigger

בונים פונקציה שמקבלת שני מספרים ומדפיסה את המספר הגדול ביניהם.

def printBigger(num1, num2): if num1 > num2: print(str(num1)) else: print(str(num2)) printBigger(1, 2) printBigger(3, -6) printBigger(5, 5)
כאשר שני המספרים שווים, הקוד בדוגמה מגיע ל־else ומדפיס את המספר השני — שהוא אותו ערך.

שלב 6 · פונקציה שמחזירה ערך

כאשר רוצים שהפונקציה תחזיר תוצאה לשימוש בהמשך, משתמשים ב־return.

def average(num1, num2): return (num1 + num2) / 2 avg = average(100, 90) print(str(avg))

print

מציג מידע למסך.

return

מחזיר ערך שאפשר לשמור במשתנה או להשתמש בו בפונקציה אחרת.

שלב 7 · ifPass משתמשת ב־average

פונקציות יכולות לעבוד יחד: פונקציה אחת מחשבת, ופונקציה אחרת מחליטה מה לעשות עם התוצאה.

def average(num1, num2): return (num1 + num2) / 2 def ifPass(grade1, grade2): avg = average(grade1, grade2) if avg <= 55: print("Failed") else: print("Average is " + str(avg)) ifPass(90, 100) ifPass(40, 50)

בדיקת איכות

שם ברור: שם הפונקציה מתאר פעולה.
הזחה: גוף הפונקציה מוזח פנימה.
קריאה: יש לפחות קריאה אחת לכל פונקציה.
בדיקה: קוראים לפונקציה עם כמה ערכים.
המידע נשמר בדפדפן המקומי של המכשיר בלבד.
