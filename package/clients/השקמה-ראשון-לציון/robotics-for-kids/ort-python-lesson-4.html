מהי לולאה?

לולאה היא קטע קוד שחוזר על עצמו מספר פעמים. במקום להעתיק את אותו קטע שוב ושוב, נותנים למחשב הוראה לחזור.

למה זה חשוב?

  • חוסך שכפול קוד.
  • מקל על תיקונים.
  • מאפשר להריץ פעולה גם עשרות או מאות פעמים.

לולאת while

נשתמש ב־while כשאנחנו רוצים שהקוד ירוץ כל עוד תנאי מסוים מתקיים — לפעמים כשלא יודעים מראש כמה חזרות יהיו.

while עם מונה

i = 0
while i < 5:
    print(i)
    i += 1

בכל חזרה מדפיסים את i ואז מגדילים אותו ב־1. בלי השורה האחרונה הלולאה לא תיעצר.

while עם מספר אקראי

import random

n = 0
while n != 3:
    n = random.randint(0, 9)
    print(n)

import מזמן ספרייה. כאן משתמשים ב־random.randint כדי לקבל מספר אקראי בטווח כולל.

חשוב: כל שורה ששייכת ללולאה חייבת להיות בהזחה פנימה.

לולאת for והפקודה range

נשתמש ב־for כשאנחנו יודעים מראש על איזה רצף לעבור או כמה חזרות לבצע.

range(stop)

for i in range(10):
    print(i)

מדפיס 0 עד 9. מתחיל מ־0 ועוצר לפני 10.

range(start, stop)

for i in range(1, 10):
    print(i)

מדפיס 1 עד 9. ה־stop הוא אחד אחרי המספר האחרון.

range(start, stop, step)

for i in range(1, 10, 2):
    print(i)

מדפיס 1, 3, 5, 7, 9. ה־step קובע את גודל הקפיצה.

שילוב לולאות ותנאים

אפשר לבדוק תנאי בתוך הלולאה ולבצע פעולה רק כשמספר מתאים לכללים.

for num in range(1, 11):
    if num % 2 == 0:
        print(num)
הסימן % מחזיר שארית. אם השארית בחלוקה ל־2 היא 0 — המספר זוגי.

break ו־continue

break — לעצור את הלולאה

for x in range(5):
    if x != 0 and x % 3 == 0:
        break
    print(x)

ברגע שמגיעים ל־break, הלולאה נפסקת לגמרי.

continue — לדלג לחזרה הבאה

for x in range(1, 5):
    if x % 3 == 0:
        continue
    print(x)

כשמגיעים ל־continue, מדלגים על שאר הקוד באותה חזרה וממשיכים לחזרה הבאה.

תרגול כיתה

תרגיל 1 · קלט עד עצירה

כתבו קוד שקולט ערכים מהמשתמש בלולאה כל עוד המשתמש לא הזין את הספרה 4. כשהמשתמש הזין 4 — ריצת הקוד תיפסק.

value = input("הכניסו מספר: ")
while value != "4":
    value = input("נסו שוב: ")
print("עצירה")

תרגיל 2 · מספרים מתאימים

הדפיסו את כל המספרים בין 1 ל־100 שהם גם אי־זוגיים וגם מתחלקים ב־3 ללא שארית.

for num in range(1, 101):
    if num % 2 != 0 and num % 3 == 0:
        print(num)
