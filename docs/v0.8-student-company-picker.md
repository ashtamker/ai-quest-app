# AI Quest v0.8 — Non-Spoiling Student Company Picker

Date: 2026-06-24

## User direction

The student company-selection screen should not filter by category/field because that can reveal answers to company questions. Admin UI is currently inconvenient in grid form, but admin redesign is deferred to a later stage.

## Completed

- Updated student company-selection screen to avoid revealing company field, description or ability before opening a task.
- Added company-name search only.
- Added non-spoiling tabs:
  - open
  - completed
  - needs photo retake
  - all
- Added random company button.
- Company cards now show only:
  - company name
  - difficulty level
  - task status
  - neutral note explaining that details are revealed inside the task
- Preserved full company field/description/abilities inside the company task screen, after the team chooses to open the task.
- Added `needsPhotoFixCompanies` team state:
  - new teams start with `[]`
  - invalid photo review adds the company id
  - completing the company again removes it from the fix list
  - team reset clears it
- Updated both JSON-server and localStorage fallback behavior.

## Verification

Passed:

- `npm test`
- Module imports for StudentApp, use cases and repositories
- Local API smoke test:
  - created team with `needsPhotoFixCompanies: []`
  - created submission
  - marked submission invalid
  - verified company moved to `needsPhotoFixCompanies`
  - verified company was removed from `completedCompanies`
- Smoke-test runtime data was cleaned.

## Deferred

- Admin UI redesign. Current grid is not convenient and should be redesigned later as a searchable table/list editor.
