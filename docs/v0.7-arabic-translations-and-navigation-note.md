## User concern

## Recommended navigation approach

Avoid category/field filters in the student UI. Prefer non-spoiling navigation:

- Search by company/logo name only.
- Show not-started / completed / needs-new-photo states.
- Filter by difficulty level only, if needed.
- Random company suggestion: “תנו לנו חברה אקראית”.
- Physical route/zone filter only if based on a park map and not on the company field.
- Recently opened / nearby / mission queue, if available later.
